# MAX | Explore MomentusMAX Screens [Interaction]

Open-exploration Interaction for the navigation course. The learner chooses any of the seven MomentusMAX screens (Today's Focus, Opportunities, Tasks, Calendar, Analytics, Logs, Settings), sees a preview of the real screen, and reads what it does and how it helps. Highlighted areas on each preview open a short explanation.

## Learning items
- Identify what each MomentusMAX screen is for
- Preview the main areas of each screen
- Connect each screen to the work it supports

## Files
- `index.html`: the Interaction. Self-contained, with the captures and font embedded.
- `.nojekyll`: tells GitHub Pages to serve the file as is.

## Embed in Genially
Use the HTML or embed widget. The stage is 1920 x 1176 so the selector bar is not letterboxed.

```html
<iframe src="https://lroulywhite.github.io/MAX-explore-screens/" title="MAX | Explore MomentusMAX Screens [Interaction]"
  width="1920" height="1176" style="border:0;width:100%;height:100%;" allowfullscreen loading="lazy"></iframe>
```
Recommend full-screen mode.

## Publish
1. Create the repo `MAX-explore-screens` on GitHub.
2. Push these files to the `main` branch.
3. Settings > Pages > Deploy from a branch > `main` / root.
4. Wait a few minutes. If the live page looks stale, it is usually caching.

## Before sharing widely
- Product or Security must confirm the demo data in the captures is mock. A Pages site is reachable by URL even when the repo is private.
- Product to confirm the items listed as inferred in the build summary (Opportunity details description, aging holds in Analytics, admin wording in Settings).
- Recapture Today's Focus if its layout has changed.
